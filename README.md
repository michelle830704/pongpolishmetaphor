Reef Rally — Ocean Pong
A C# 3D underwater Pong game with fish paddles, a pearl ball and adapted Kenney CC0 assets. Original mechanics are preserved, with added animations, sounds, bubbles and camera effects.
- Run: Open in Godot 4.5 .NET, build and press F5.
- Controls: Controller sticks move paddles; P toggles polish; R restarts.
- Validation: Build and runtime checks passed.
- Submission: Complete playtest notes and include your repository URL, Git username and commit hash.
